# Extreme Programming 作业项目计划书

> **项目名称（暂定）：** Contact Manager（通讯录管理系统）  
> **课程：** Software Engineering (FZU–MU)  
> **作业主题：** Extreme Programming（极限编程）  
> **截止时间：** 2026 年 11 月 17 日 23:59  
> **项目状态：** 初步规划，尚未进入详细设计

## 1. 项目简介

本项目计划开发一个基于 Web 的通讯录管理系统，采用前后端分离架构。用户可以通过浏览器管理联系人、收藏常用联系人、为同一联系人保存多种联系方式，并通过 Excel 文件批量导入或导出通讯录。

系统使用本地 SQLite 数据库持久化保存信息，以确保正常关闭、重新启动应用后数据仍然保留。本项目以完成课程要求、保证功能完整和运行稳定为首要目标，同时实践 Git 版本管理及 Extreme Programming 相关的软件开发协作流程。

## 2. 技术栈

| 层次 | 技术 | 用途 |
| --- | --- | --- |
| 前端 | Vue 3 | 实现页面、组件和用户交互 |
| 前端开发与构建 | Vite | 运行开发服务器并构建前端产物 |
| 后端 | Python + Flask | 提供 HTTP API、处理业务逻辑与文件操作 |
| 数据库 | SQLite | 在后端本地磁盘持久化保存联系人信息 |
| 前后端通信 | HTTP + JSON | 前后端之间传输业务数据；Excel 文件使用相应的文件上传/下载方式 |
| 版本管理与协作 | Git + GitHub | 代码管理、提交记录、Release 与 Pull Request |
| Excel 处理 | Python Excel 处理库（具体选型待定） | 读取与生成 Excel 文件 |

**架构概述：** 浏览器中的 Vue 前端通过 HTTP 请求与 Flask 后端通信；后端负责访问 SQLite 数据库，前端不直接操作数据库。

## 3. 拟实现功能

### 3.1 联系人基础管理

- 新增联系人。
- 查看联系人列表及详细信息。
- 编辑或删除已有联系人。
- 将联系人数据保存到本地数据库，并在程序重新启动后恢复。

### 3.2 联系人收藏（25 分）

- 标记或取消标记收藏联系人。
- 方便地查看已收藏的联系人。
- 持久化保存收藏状态。

### 3.3 多种联系方式（10 分）

- 支持同一联系人保存多条联系方式。
- 支持电话号码、电子邮箱、社交账号、地址等类别。
- 允许用户管理已有联系方式。

### 3.4 Excel 导入与导出（25 分）

- **导出：** 将联系人及相关信息导出为 Excel 文件，每位联系人占一行，不同信息类别分列，并保留其多种联系方式。
- **导入：** 从符合约定格式的 Excel 文件读取联系人信息并加入通讯录。
- 对无效文件或错误数据提供必要的提示；验证导出文件能够正确重新导入。

### 3.5 页面与交互（10 分）

- 提供清晰、易用的 Web 界面。
- 支持主要功能的操作反馈、基础表单检查和错误提示。

### 3.6 可选功能

- **云端部署（额外 15 分）：** 如进度允许，部署可通过公网访问的完整 Web 应用；是否满足加分标准以课程要求为准。
- 搜索、排序等辅助体验功能：视时间和实际需要决定，不作为当前必做范围。

## 4. 开发与验证原则

- 在开始实现前讨论模块职责、协作方式和基本代码规范。
- 采用 Git 进行阶段性提交，保留可追溯的开发记录。
- 优先完成必做功能，再考虑可选功能和云端部署。
- 验证联系人数据在正常重启后仍存在，并测试收藏、多联系方式及 Excel 导入导出的完整流程。
- 记录开发中遇到的问题、解决方法与个人工作投入，为博客和 PSP 表格提供依据。
